#### 🤖 [JobFit-AI](https://job-fit-ai-gray.vercel.app)
An interactive AI-powered application designed to streamline candidate interview workflows and job readiness using the **Google Gemini AI API**.

* **Key Features:** Secure JWT cross-origin authentication with HTTP-only cookies, automated interview routing, and custom AI evaluation pipelines.
